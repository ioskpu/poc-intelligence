# POC Intelligence

ProofOfConsistency Intelligence Platform is a lightweight SaaS interface for
quantitative market intelligence generated by the existing Futures Lab backend.

The platform is not a trading platform. It does not execute trades and does not
provide financial advice.

## Mission

Expose statistical intelligence in a clear dashboard experience:

- Market rankings
- Opportunity rankings
- Pattern discovery results
- Regime analysis
- Quantitative summaries generated outside the frontend

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

- Landing page: `http://localhost:3000`
- Dashboard: `http://localhost:3000/dashboard`

Private live integration variables:

- `FUTURES_LAB_API_BASE_URL`: Futures Lab API base URL.
- `FUTURES_LAB_INTERNAL_API_KEY`: Internal API key for dashboard state access.
- `FUTURES_LAB_DATABASE_URL`: Read-only Postgres connection string for
  historical comparison queries.
- `FUTURES_LAB_DASHBOARD_STATE_PATH`: Private dashboard state endpoint path.
- `FUTURES_LAB_REQUEST_TIMEOUT_MS`: Optional request timeout override.
- `POC_INTELLIGENCE_API_URL`: Public backend API base URL for Private Beta
  requests, admin reads and health checks.

If those private variables are omitted, POC Intelligence runs in public demo
mode using local mock data only.

## Build Instructions

Start the production server after building:


## Architecture Overview

The application uses Next.js App Router, TypeScript, TailwindCSS and
shadcn-compatible UI primitives.

Primary source layout:

- `src/app`: App Router pages and layouts.
- `src/components`: Shared layout and UI components.
- `src/features`: Product features grouped by domain.
- `src/services/api`: API access boundary.
- `src/types`: Shared TypeScript contracts.
- `src/lib`: Small shared utilities.

All data access must go through `src/services/api`. Phase 1 uses typed mock
data behind that boundary so the future Futures Lab integration can replace the
implementation without rewriting pages or feature components.
